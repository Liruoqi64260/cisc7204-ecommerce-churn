# GitHub Public Repository — Setup and Structure

## 1. Repository purpose

The public repository is the code-and-documentation companion to the submitted archive. It makes the analysis inspectable and reproducible beyond the UMMoodle submission, while deliberately excluding large datasets and personal information.

**Suggested repository name:** `cisc7204-ecommerce-churn`
**Visibility:** Public
**Default branch:** `main`
**License:** MIT (teaching project)
**Short description:** *Customer churn prediction for a Brazilian e-commerce marketplace — CISC7204 final project (Class B, Team 05).*

## 3. What is committed and what is not

| Asset | Committed? | Reason |
| :--- | :--- | :--- |
| Notebook, figures, codebook, dataset description | Yes | Complete analysis and documentation. |
| `cleaned_customer_features.csv.gz` (7.5 MB) | Yes | Gzip-compressed analytic dataset; notebook decompresses automatically, so the repository holds the entire project and runs without extra downloads. |
| Raw Olist CSV tables | No | Publicly downloadable from Kaggle; not required for reproduction because the cleaned analytic table is committed. |
| `.ipynb_checkpoints`, `__pycache__`, `.venv` | No | Generated by tooling; listed in `.gitignore`. |

To reproduce from a fresh clone, install the dependencies in `requirements.txt` and run the notebook from the repository root; the committed gzip dataset is auto-decompressed to `datasets/cleaned_customer_features.csv` on first run. The nine raw Olist tables can additionally be downloaded from the public Kaggle dataset if the upstream cleaning pipeline needs to be re-executed.

## 5. Publishing workflow

```bash
git init -b main
git add README.md requirements.txt notebooks/ figures/ datasets/ codebook/ docs/
git commit -m "Add CISC7204 final project: e-commerce churn analysis"
git branch -M main
git remote add origin https://github.com/<USERNAME>/cisc7204-ecommerce-churn.git
git push -u origin main
```

After pushing, enable GitHub Pages (Settings → Pages → Deploy from branch `main` / root) if a rendered HTML report is desired, and paste the repository URL into the project README.

---

## 6. Relationship to the submitted archive

The UMMoodle archive `cisc7204-Class_B-Team_05-FinalProjectArchive.zip` is the graded artefact and contains the analytic CSV plus the executed notebook and all documents. The GitHub repository is a public, lightweight mirror of the code, figures and documentation; it does not replace the archive. Every team member submits the archive individually to the **Class HOME UMMoodle forum**, not the main CISC7204 UMMoodle site.
